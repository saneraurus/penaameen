# PENA AMEEN Client Decision Register

**Phase:** 1 — Product Discovery
**Status:** Open client decisions required to finalize dependent architecture and implementation scope. This register consolidates decision points; it does not replace `docs/UNKNOWN-REGISTRY.md`, which remains the source registry for unresolved evidence/data.

## How to use this register

- A decision can be answered by **approve**, **choose**, or **explicitly defer/exclude** the capability. Silence is not an approval.
- A `CRITICAL` decision blocks the MVP commerce loop, migration safety, legal readiness, or final architecture.
- A `HIGH` decision blocks the affected public/operational capability and should be resolved before final architecture so it is not guessed.
- A `MEDIUM` decision can be explicitly deferred, but its deferment must be recorded before architecture scope is finalized.
- This register does not repeat decisions already confirmed: PENA AMEEN is a **single-vendor** commerce platform, not a multi-vendor marketplace; payment/shipping remain provider-agnostic until selection.
